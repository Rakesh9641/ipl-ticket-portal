# 🏏 IPL Ticket Portal

A web-based application developed using Python that allows users to browse IPL matches, book tickets, and manage reservations through a simple and user-friendly interface.

---

## 📌 Features

- 🔐 User Registration & Login
- 🏟️ View IPL Match Schedule
- 🎫 Book IPL Match Tickets
- 👤 User Dashboard
- 💾 Database Integration
- 📱 Simple and Responsive Interface

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
-  MySQL

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/Rakesh9641/ipl-ticket-portal.git
```

2. Navigate to the project folder

```bash
cd ipl-ticket-portal
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser

```
http://127.0.0.1:5000/
```
